# ECHO — 昨日の自分を超えろ

「昨日の自分（エコー）」と戦う 1 対 1 のブラウザ用アクションゲーム。
タイトル画面はゲームの進行によって姿を変える。

## ストーリー

DAY 1 から DAY 10 まで、毎日「昨日の自分」と戦う。**その日のプレイヤーの操作はすべて記録され、
翌日のエコーがそれを再現してくる。** DAY 1 のエコーだけは記録が無いので通常の AI で動く。
DAY 10 は 5 能力すべてを持つ PERFECT ECHO。

再現するのは座標ではなく**判断**（攻撃・パリィ・能力の順番と間合い）なので、

- 射程外なら昨日の攻撃をそのまま出さず、ジリジリ間合いを詰めてから振る
- 1 発目のあとに逃げられたらコンボを中断して追いかける
- 「空振りを待って殴る」を 2 回やられると、3 回目からは振るふりをして止まるフェイントを混ぜてくる
- 3 割ほどは記憶ではなく今のプレイヤーへの反応で動く

昨日の行動を再現している間はエコーの体に**紫のノイズ**が走る。光ったら次に来るのは昨日の自分の手だ。

## 戦闘のテンポ

反射神経よりも「昨日の自分をどれだけ覚えているか」で勝てるように、見てから動ける速さにしてある。

- 斬撃は**プレイヤーもエコーも 0.7 秒の予備動作**（アークが太く大きくなる）。構えを見てから、ガード・パリィ・瞬歩のどれで返すか選べる
- 連撃は **3 撃まで**。振り切ると 0.9 秒の大きな隙ができる
- 能力は即発動しない。**紫の輪＋音で 0.35 秒予告**してから効果が出るので、《瞬歩》で背後を取られる前に反応できる

## 遊び方

依存関係なし。静的サーバーで開くだけ（ES Modules を使うため `file://` では動かない）。

```bash
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## 操作

| キー | 動作 |
| --- | --- |
| ← → | 移動 |
| J / Space | 斬撃 |
| K | パリィ |
| 1〜5 | 能力（瞬歩 / 反射 / 時止め / 残像 / 炎刃） |
| Enter | 決定 |
| Esc | 戻る・リタイア |

## 能力

最初は能力を一つも持たず、剣だけで戦う。エコーを 1 体倒すごとに能力が 1 つ解放される
（DAY 1 は剣のみ → DAY 2 で瞬歩 → … → DAY 6 以降は 5 つすべて）。
未解放の能力は HUD で 🔒／？？？ 表示になる。

| 能力 | 効果 |
| --- | --- |
| 瞬歩 | 前方へ高速移動、移動中は無敵 |
| 反射 | 一定時間、受けたダメージを相手に返す |
| 時止め | 相手の動きを一定時間止める |
| 残像 | 身代わりを出し、次の被弾を 1 回無効化 |
| 炎刃 | 次の 3 回の斬撃に追加ダメージ |

## 進行とタイトル画面の変化

初回のタイトル画面は `PLAY` と `設定` だけ。

```
ECHO
昨日の自分を超えろ
▶ PLAY
⚙ 設定
```

PERFECT ECHO を倒し **《能力を奪う》** を選ぶと、タイトルに戻る瞬間に画面へノイズが走り、
`ENDLESS MODE`（紫に発光）と `実績` が出現する。

```
ECHO
昨日の自分を超えろ
▶ PLAY
🟣 ENDLESS MODE
🏆 実績
⚙ 設定
```

## エンドレスモード

DAY 1 から連戦し、何日生き残れるかを競う。エコーは日ごとに強くなり、
**前日にプレイヤーが多用した能力を優先して使う**ようになる。

## 実績（全 13 / エンドレスモード専用）

| 実績名 | 条件 |
| --- | --- |
| 十日を超えた者 | 10 日間生き残る |
| 一か月前の俺 | 30 日間生き残る |
| 半世紀の昨日 | 50 日間生き残る |
| 昨日っていつだ？ | 100 日間生き残る |
| 無傷の今日 | エコーをノーダメージで倒す |
| 能力なんていらない | 能力を一度も使わずにエコーを倒す |
| それ、知ってる | エコーの攻撃を 5 回連続でパリィする |
| 昨日の癖 | エコーの《瞬歩》攻撃を 3 回連続で回避する |
| 全部返す | 《反射》によるダメージでとどめを刺す |
| 1秒あれば十分 | 《時止め》発動中にエコーを倒す |
| 残像対残像 | エコーとほぼ同時に《残像》を発動する |
| 炎の昨日 | 《炎刃》による攻撃でとどめを刺す |
| もう一人の達人 | 5 つの能力すべてを使ったエコーを倒す |

生存日数系の 4 つは未解除でも条件が見えるが、下の 9 つは解除するまで **「？？？」** で条件も隠される。

## セーブ

進行状況・実績・設定は `localStorage`（キー `echo.save.v1`）に保存される。
設定画面からセーブデータを削除できる。
